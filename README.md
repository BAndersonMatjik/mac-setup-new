# mac-setup-new
New MacBook setup.

## Install Scripts

Run Homebrew install first:

```sh
sh ./install-homebrew.sh
```

Then install Oh My Zsh:

```sh
sh ./install-omz.sh
```

Then install all packages from the Brewfile:

```sh
sh ./install-brewfile.sh
```

For non-interactive runs, set `AUTO_APPROVE=1` before each script.
